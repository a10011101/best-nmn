# best-nmn.com Landing Page

High-converting landing page for AlphaVita Labs NMN 500mg.

Hosted on GitHub Pages → DNS pointed to best-nmn.com

## Deploy
Push to `main` branch → GitHub Pages auto-deploys.

## DNS Setup
Point best-nmn.com CNAME to: `[your-github-username].github.io`
Or A records to GitHub's IPs: 185.199.108.153 / 185.199.109.153 / 185.199.110.153 / 185.199.111.153

## Structure
- `index.html` — Main landing page
- `CNAME` — Custom domain file for GitHub Pages
